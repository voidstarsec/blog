Building and Deploying the VoidStar Security Blog

This blog is a static site built with Pelican and deployed to GitHub Pages via ghp-import.

Prerequisites

  • Python 3
  • The blog-resources repo cloned alongside this one at /home/wrongbaud/projects/vss/blog-resources/ (contains the Pelican plugins and the pelican-bootstrap3 theme)

Setting Up the Environment

# Create and activate the virtual environment
python3 -m venv pelican-venv
source pelican-venv/bin/activate

# Install dependencies
pip install pelican markdown ghp-import pelican-just-table

Writing a Post

Add a new Markdown file to the content/ directory. The naming convention is YYYY-MM-DD-slug.md. Posts use standard Pelican metadata headers (Title, Date, Category, Tags, Author, etc.).

Building Locally

source pelican-venv/bin/activate

# Quick build (uses pelicanconf.py)
make html

# Or the custom target that applies the bootstrap3 theme and CSS tweaks:
make custom

The custom target does three things:

  1. Runs Pelican with the pelican-bootstrap3 theme from blog-resources
  2. Runs prep.sh to post-process the HTML (adds Bootstrap table classes and image styling)
  3. Copies vss-style.css into output/theme/css/style.css

Local Preview

# Serve with auto-regeneration on file changes
make devserver

# Or just serve the already-built output
make serve

The site will be available at http://localhost:8000.

Deploying to GitHub Pages

make custom

The custom Makefile target already includes the ghp-import step, which pushes the output/ directory to the gh-pages branch on origin. The -n flag adds a .nojekyll file and -p pushes automatically.

Alternatively, you can deploy in two steps:

make publish         # Build with publishconf.py (production settings)
make github          # Push to gh-pages branch

Key Files

File Purpose
pelicanconf.py Main site config (site name, URL, plugins, theme, sidebar, social links)
publishconf.py Production overrides (atom feeds, DELETE_OUTPUT_DIRECTORY)
Makefile Build/serve/deploy targets
prep.sh Post-build HTML tweaks (table classes, image styling)
vss-style.css Custom CSS overrides for the bootstrap3 theme
content/ Markdown source files for blog posts
output/ Generated static site
